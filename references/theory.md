# 理论与方法参考

只读你需要的那一节。目标：让每节课都符合"人能学会"的机制，而不是"内容看起来完整"。

---

## 1. 范围收敛（Scope Drilling）

宽泛主题是学习最大的敌人。收敛动作：

1. **换动词**：把"学 X"换成可观察的动作——解释 / 判断 / 实现 / 调试 / 设计 / 评估。
2. **加约束**：加一个真实场景。"学 SQL" → "能写出带窗口函数和 CTE 的月度留存报表"。
3. **切一片**：选一条端到端最小路径，而不是按教材目录横扫。其余进"范围外"。
4. **验可测性**：如果没法在 10 分钟内出题验证，说明目标还不够具体。

判定"够聚焦"的标准：能写出**一条** 20 分钟内可完成的练习，且完成后能观察到能力变化。

### 最小可用核心（MVC）

问三个问题找核心：
- 哪个概念一旦不懂，其余全部读不懂？（前置瓶颈）
- 哪个概念用得最频繁？（杠杆）
- 哪个概念最能解释"为什么这样设计"？（生成性原则）

MVC 通常只占全量的 20%，却承载 80% 的后续理解。**先教 MVC，再按需求扩展。**

## 2. 认知负荷理论（Cognitive Load Theory, Sweller）

三种负荷：

| 类型 | 来源 | 处理 |
| --- | --- | --- |
| 内在负荷（intrinsic） | 元素数量 + 元素间交互复杂度 | 拆 chunk、分段（segmenting）、先低交互后高交互 |
| 外在负荷（extraneous） | 糟糕的呈现方式 | 消除：分心信息、图文分离、重复表述、无关装饰 |
| 生成负荷（germane） | 用于建构 schema 的心智努力 | 保留并引导：自我解释、对比、预测 |

具体规则：

- **分段原则**：学习者控制的按步呈现 > 一次性全部呈现。每步一个可消化单元。
- ** Signaling**：用标题、箭头、高亮告诉学习者"现在看这里"。不要让他自己找重点。
- **空间/时间邻近**：图和对应文字放一起，不要"见图 3"。
- **冗余原则**：同一内容不要同时用"图 + 逐字朗读文本 + 长段解释"三种同构表征，会增加外在负荷。用图 + 关键词即可。
- **通道原则**：视觉图 + 口头/文字简述 优于 视觉图 + 视觉长文。
- **专长逆转效应（expertise reversal）**：对新手有效的详细讲解，对进阶者是干扰。有基础的人应直接面对问题，删掉 worked example。
- **先例后题（worked example effect）**：新手先读完整解法再练习，效率高于直接硬做。
- **渐隐（fading）**：完整范例 → 留最后一步 → 留中间步 → 独立完成。
- **元素交互性**：同时必须考虑的因素越多越难。一次只放开一个变量。

**每节课自检**：新元素 ≤ 3？有没有可以删掉而不损失理解的内容？有没有让学习者主动加工，而不只是接收？

## 3. 刻意练习（Deliberate Practice, Ericsson）

不是"多练"，是**针对薄弱子技能、带即时反馈、在能力边缘反复修正**。

设计四要素：

1. **拆到子技能**：不是"练写作"，是"练把结论前置的开头句"。子技能要小到能在一轮内改好。
2. **明确成功标准**：练习前就说清"什么样算对"。模糊标准产生模糊练习。
3. **即时、具体的反馈**：指出偏差 + 给出可执行的修正动作，并在下一轮**立刻**再试一次同样的子技能。
4. **在难度边缘**：成功率约 70–85% 最理想。全对=太简单，全错=拆得不够细。

教练动作：先示范 → 学习者模仿 → 你只指出**一个**最重要的偏差 → 立即重做。一次只改一个点，多了改不动。

## 4. 提取练习与间隔（Retrieval Practice & Spacing）

- **测试效应**：提取本身比重复阅读更能巩固记忆。所以宁可少讲多测。
- **间隔效应**：分散到多次的效果远好于集中突击。间隔按 1/3/7/16/35 天扩展。
- **交错（interleaving）**：混合不同主题/题型练习，牺牲当下流畅感换取长期迁移能力。这正是"穿插旧知识点"的理论依据。
- **必要难度（desirable difficulties）**：让学习稍微费劲（延迟反馈、变换情境、闭卷回忆）能提升长期保持。不要为了"顺滑"而降低难度。
- **信心校准**：答前记录信心，答后对比。校准错误（自信地错、心虚地对）比单纯答错更值得干预。

## 5. 双重编码与具体化（Dual Coding）

- 语言表征 + 视觉表征并行编码，回忆路径更多。
- 有效做法：概念图、对比表、流程图、时间线、状态机、坐标系、层级树、因果链。
- 图的三种用法：**组织**（结构关系）、**解释**（机制运转）、**转换**（同一内容的另一种表征，用来检验理解）。
- 反例也要可视化：把"错误做法"画出来，与正确路径并排。对比比单例更能形成判别力。
- 类比必须带**失效边界**："它像 X，但在 Y 处不像"。没有边界的类比会制造错误概念。

## 6. 认知学徒制与 4C/ID

**认知学徒制（Cognitive Apprenticeship）** 六步：建模 → 指导 → 脚手架 → 退隐 → 表达 → 反思 → 探索。
对应到本 skill：示范 → 递进提示 → 渐隐 → 学习者复述 → 错误复盘 → 独立迁移。

**4C/ID（van Merriënboer）** 四个成分：
1. **学习任务**：从简到繁的完整任务序列（不是知识点的孤立练习）。
2. **支持信息**：讲"是什么、为什么"，在学习任务前给，可随时查。
3. **程序信息**：讲"怎么做"，就在做的时候给，逐步撤掉。
4. **部分任务练习**：只对确实需要自动化的子技能做重复训练。

要点：**始终围绕完整任务组织学习**，不要先学完所有理论再动手。

## 7. 专长发展与表征转换（Expertise）

新手→专家的变化：
- 表征从"表层特征"转向"深层结构/原理"。
- 从"逐步推理"转向"模式识别 + 组块"。
- 从"单一解法"转向"多方案权衡"。

教学含义：
- 新手需要**明确规则 + 范例**，并训练"看到特征 → 联想到原理"。
- 进阶者需要**辨别训练**：给一堆相似情境，判断该用哪条原理（这是从多点走向关联的关键）。
- 专家需要**边界与权衡**：什么时候规则失效、代价是什么。

## 8. chunk 设计与排序

一个好的 chunk：
- 有一个**单一主张**（一句话能说完）。
- 有**可观察的产出**（能画/能写/能判断）。
- 有**明确前置**（缺什么就学不动）。
- 体量 ≈ 8–15 分钟交互。

排序策略，按优先级：
1. 依赖顺序（前置必须先）
2. 杠杆顺序（高频先用）
3. 可感知顺序（先能看见效果的，维持动机）

不要用"教材章节顺序"当默认答案；教材顺序服务作者叙事，不服务学习曲线。

---

## 9. 动机与坚持（轻量使用，别过度）

- **自我决定理论**：自主（让他选切片）、胜任（难度在边缘、及时看到进步）、关联（连到他的真实目标）。
- 用"能力可见化"维持动机：每过一关，更新能力清单，展示他**现在能做什么**。
- 避免空洞鼓励；具体的进步证据比赞美有效。
